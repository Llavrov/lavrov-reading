# Лёва Лавров — конспекты

Личная читальня: конспекты книг и статей своими словами, с вырезками из первоисточников и ссылками. Удобно читать с телефона.

Минималистичная верстка в духе читалок эссе — узкая колонка, серифный шрифт, тёмная и светлая темы, прогресс чтения.

## Стек

- Next.js 16 (App Router) + React + TypeScript
- SCSS-модули
- Статьи в MDX (`content/articles/*.mdx`)
- Деплой на Vercel

## Как добавить статью

Создать файл `content/articles/<slug>.mdx` с фронтматтером:

```mdx
---
title: "Заголовок"
description: "Короткое описание для SEO и списка."
date: "2026-07-12"
tags: ["тема"]
sources:
  - label: "Автор, издание, год"
    url: "https://example.com"
---

Текст разбора. Вырезки из источника оформляются так:

<Excerpt source="Автор, год">
Цитата из первоисточника.
</Excerpt>
```

Статья автоматически попадёт на главную, в sitemap и RSS. `git push` → Vercel деплоит.

## Локально

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # прод-сборка
```
