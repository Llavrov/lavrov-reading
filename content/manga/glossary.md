# Глоссарий: язык вебтун/манга-производства

Термины, чтобы дальше говорить на одном языке. Разбито по темам.

## Форматы и рынок
- **Манга** - японский комикс. Обычно чёрно-белый, читается справа налево, страничная вёрстка (2 страницы разворотом), собирается в тома (танкобоны).
- **Манхва** - корейский комикс. Часто цветной, вертикальный скролл.
- **Маньхуа** - китайский комикс. Тоже часто цветной/вертикальный.
- **Вебтун (webtoon)** - формат вертикальной бесконечной ленты под телефон. Родом из Кореи (Naver Webtoon). Именно этот формат в топе Remanga и его проще всего генерить ИИ.
- **Remanga** - RU-площадка-читалка манги/манхвы/вебтунов с авторским разделом (руманга). Наша цель релиза.
- **Танкобон / том** - собранный сборник глав (для печатной манги).
- **Глава / эпизод** - единица публикации вебтуна. У вертикального вебтуна = один длинный «свиток» на 30-80 панелей.

## Структура страницы и ритм
- **Панель (кадр, panel)** - одна «картинка» в комиксе. Из панелей собирается сцена.
- **Гаттер (gutter)** - пустое пространство между панелями. В вебтуне вертикальный гаттер = пауза/течение времени. Управляешь ритмом, меняя высоту отступа.
- **Splash / спред** - крупный кадр на весь экран для драматичного момента (аналог разворота в печатной манге).
- **Скролл как время** - главный приём вебтуна: чем длиннее пустой скролл, тем дольше «пауза» в восприятии.
- **Раскадровка / сториборд / thumbnails** - грубый набросок раскладки панелей до чистовой отрисовки. Здесь решается ритм.
- **Переякорение** - первые 3-5 панелей эпизода, напоминающие кто/где мы (читатель вернулся через неделю).
- **Клиффхэнгер** - обрыв на крючке в конце главы, чтобы вернулись.

## Текст на странице
- **Бабл (balloon, речевой пузырь)** - облачко с репликой. Бывает мысленный (облачко с пузырьками), речевой (овал с хвостом), крик (зубчатый).
- **Тайпсеттинг** - расстановка текста, баблов и звуков на готовых картинках. Обычно последний этап.
- **SFX (звуковые эффекты)** - нарисованные звуки («БАМ», «шшш»). Оформляются декоративным шрифтом.
- **Онамотопея** - звукоподражание (то же, что SFX по сути).
- **Кернинг / лидинг** - межбуквенный / межстрочный интервал в тексте бабла.

## ИИ-генерация
- **Stable Diffusion (SD)** - открытая модель генерации картинок, которую можно гонять локально бесплатно. Основа бюджетного стека.
- **ComfyUI / Automatic1111 (A1111) / Forge** - программы-интерфейсы для запуска Stable Diffusion. ComfyUI - нодовый (гибкий), A1111/Forge - проще на старте.
- **Чекпоинт (checkpoint, модель)** - основной файл модели, задающий стиль/качество. Для аниме: Illustrious, Pony, NoobAI.
- **SDXL** - поколение архитектуры SD (нужно ~8GB VRAM). На нём стоят топовые аниме-чекпоинты.
- **LoRA** - маленькая до-обученная надстройка на модель (~150MB). Тренируешь на своём персонаже → он стабильно воспроизводится. Главный метод консистентности героя.
- **IP-Adapter** - подача картинки-референса как визуального якоря без тренировки. Быстро, но потолок ~85%.
- **ControlNet** - управление структурой картинки. **OpenPose** - задаёшь скелет-позу, модель рисует персонажа в этой позе.
- **Inpaint (инпейнт)** - перегенерация только выделенной области (правишь руку/лицо, остальное не трогаешь).
- **Seed** - число-зерно генерации. Один seed + один промпт = похожий результат. Фиксируешь для стабильности.
- **Промпт / негативный промпт** - текстовое описание что нарисовать / чего избегать.
- **Danbooru-теги** - система тегов (`1girl, masterpiece, best quality`), которую понимают аниме-чекпоинты.
- **VRAM** - память видеокарты. От неё зависит, потянешь ли локальную генерацию (нужно 8GB+).
- **Civitai** - крупнейший бесплатный каталог чекпоинтов и LoRA.
- **RemBG** - инструмент вырезания персонажа с фона (для коллажа).
- **Регенерация / батч** - генерация пачки вариантов, из которых выбираешь лучший.

## Драматургия (см. characters-guide.md подробно)
- **Want vs Need** - чего герой ХОЧЕТ (внешняя цель) vs что ему на самом деле НУЖНО (внутренняя потребность).
- **Ghost / Wound** - рана из прошлого, породившая ложное убеждение героя.
- **Lie / Misbelief** - ложь, в которую герой верит; арка = преодоление этой лжи.
- **Flaw** - изъян характера, вытекающий из раны.
- **Арка** - траектория изменения героя (позитивная/негативная/плоская).
- **Setup / Payoff (посев/выстрел)** - заранее посеянная деталь, которая позже «выстреливает».
- **Сквозной драматический вопрос** - главный вопрос всей серии, ответ на который = финал.
- **Hard-магия (жёсткая система)** - магия с чёткими правилами (Первый закон Сандерсона). Нужна рациональному герою, иначе умные ходы = рояль в кустах.
- **Мэри-Сью** - слишком идеальный герой без слабостей; главная ловушка истории про гения.
